# AI Interviewer & Career Coach Platform 🚀

A production-grade, AI-powered Interview Preparation and Career Coaching platform with real-time voice interviews, adaptive follow-ups, Monaco code execution, ATS resume parsing, and multi-dimensional analytics.

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite, TailwindCSS, Framer Motion, Zustand, Monaco Editor, Lucide Icons.
- **Backend**: Python Flask, SQLAlchemy, JWT Authentication, RESTful APIs, SQLite/PostgreSQL.
- **AI Engine**: OpenAI GPT / Gemini / Whisper, Web Speech API (TTS & STT), ATS scoring algorithm.
